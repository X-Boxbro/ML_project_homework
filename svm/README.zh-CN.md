## 1. 任务背景

支持向量机（SVM）是经典的线性二分类模型，其核心思想是寻找一个最大间隔分类超平面。通过引入核技巧与软间隔，SVM 能处理非线性与线性不可分问题。本实验从对偶问题出发，手写 SMO 算法实现 SVM 的求解，并通过多个对照实验理解关键超参数（C、核函数）与算法变体（SMO vs 增广拉格朗日法）对模型行为的影响。

## 2. 数据集

两类二维高斯分布样本（默认 `seed=42`）：

| 参数 | 类别 1 (+1) | 类别 2 (−1) |
|---|---|---|
| 类中心 | (1, 1) | (6, 6) |
| 每维标准差 σ | 1.0 | 1.0 |
| 每类样本数 n | 100 | 100 |

默认中心距离 ‖c2−c1‖ ≈ 7.07 ≫ 2σ ≈ 2.83，数据在默认配置下线性可分。通过将中心改为接近的配置，可构造线性不可分数据用于软间隔实验。

## 3. 算法原理

**原始问题（软间隔）**：

```text
min_{w,b,ξ}  (1/2)||w||² + C · Σ ξᵢ
s.t.  yᵢ(wᵀxᵢ + b) ≥ 1 − ξᵢ,  ξᵢ ≥ 0
```

**对偶问题**：

```text
min_α  (1/2) ΣᵢΣⱼ αᵢαⱼyᵢyⱼ(xᵢᵀxⱼ) − Σᵢ αᵢ
s.t.   Σᵢ αᵢyᵢ = 0,  0 ≤ αᵢ ≤ C
```

决策函数：`f(x) = Σᵢ αᵢyᵢ(xᵢᵀx) + b`，其中 `b = mean_{sv}( y_sv − Σᵢ αᵢyᵢ(xᵢᵀx_sv) )`。

- **SMO 算法**：每次选取一对拉格朗日乘子 (αᵢ, αⱼ) 进行解析求解，其余乘子固定，从而将大规模二次规划分解为若干两变量子问题。本实现包含完整的启发式选对、更新、 KKT 检验与支持向量识别。
- **增广拉格朗日法（AL）**：将等式约束 `Σαᵢyᵢ = 0` 通过拉格朗日乘子 λ 与惩罚项 ρ 融入目标函数，每步固定 λ, ρ 后用 L-BFGS-B 求解有界子问题，再更新 λ 与 ρ，直至约束违反足够小。
- **支持向量判定（由 KKT 条件推导）**：
  - `αᵢ = 0` → `yᵢ(wᵀxᵢ + b) ≥ 1`（非支持向量，正确分类且在间隔外）
  - `0 < αᵢ < C` → `yᵢ(wᵀxᵢ + b) = 1`（边界上的支持向量）
  - `αᵢ = C` → `yᵢ(wᵀxᵢ + b) ≤ 1`（间隔内的支持向量，含可能的误分类点）

## 4. 实验内容与结果

### 4.1 实验一：线性可分 SVM

默认可分数据上训练 SVM（C=100 近似硬间隔），绘制数据点、分类面、间隔边界与支持向量。

- 输出图像：`svm_separable.png`（左：散点图；右：SVM 结果，含支持向量标记）。

### 4.2 实验二：线性不可分数据与软间隔

通过减小两类中心距离构造重叠数据，在不同 C 值下训练软间隔 SVM，观察分类面、支持向量分布与间隔宽度的变化。

- 输出图像：`svm_nonseparable.png`（多子图展示不同 C 下的分类效果）。

### 4.3 实验三：SMO 收敛性分析

记录 SMO 迭代过程中目标函数值（对偶目标）的变化，绘制收敛曲线，观察算法随迭代次数下降至稳定值的过程。

- 输出图像：`svm_convergence.png`（对偶目标值随迭代次数的变化）。

### 4.4 实验四：惩罚系数 C 的影响

在固定数据集上将 C 从小值（软间隔倾向）逐步增大到大值（硬间隔倾向），统计每种 C 下的总支持向量数、边界支持向量数（0 < α < C）与间隔宽度 `2/‖w‖`，并绘图。

- 输出图像：`svm_c_effect.png`（三子图：支持向量总数、边界支持向量数、间隔宽度随 C 的变化）。
- 输出表格：终端打印各 C 对应的总 SV 数、边界 SV 数、间隔宽度。

### 4.5 实验五：软间隔 vs 硬间隔对比

在同组可分数据上分别训练 C=0.1（软间隔）、C=1.0（中间）、C=100（近似硬间隔）的 SVM，直观对比分类面与支持向量分布差异。

- 输出图像：`svm_soft_vs_hard.png`（三子图并列对比）。

### 4.6 增广拉格朗日法对比

使用增广拉格朗日法在相同数据上求解 SVM，对比其收敛曲线（目标值/约束违反随外层迭代的变化）与 SMO 的结果，并统计两者求解所得支持向量、分类面参数等信息。

- 输出图像：`svm_al_convergence.png`（增广拉格朗日法收敛曲线）、`svm_smo_vs_al.png`（SMO 与 AL 对比）。
- 终端打印：两种方法得到的 w、b、支持向量数量等对比信息。

## 5. 复现说明与已知问题

- 本实验依赖 `scipy.optimize.minimize` 实现增广拉格朗日法的内层子问题求解（L-BFGS-B），因此除 numpy/matplotlib 外还需要 scipy。
- 所有随机数据生成均固定 seed，重复运行结果一致；图像以 150 dpi 保存到脚本所在目录。
- 部分实验（如 C 扫描、收敛曲线）涉及较多迭代，首次运行可能需要一定时间。
