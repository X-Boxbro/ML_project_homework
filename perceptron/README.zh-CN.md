## 1. 任务背景

感知机（Rosenblatt, 1958）是最早的机器学习模型之一，也是神经网络与支持向量机等现代模型的基础。它是一个线性二分类模型：`f(x) = sign(w·x + b)`，通过"误分类驱动"的随机梯度更新寻找一个能正确划分训练集的分类超平面。本实验在二维人工数据上实现感知机原始形式，并系统观察其收敛过程与分类面演化。

## 2. 数据集

两类二维高斯分布样本（`seed=42`，测试集与训练集独立采样）：

| 参数 | 类别 1 (+1) | 类别 2 (−1) |
|---|---|---|
| 类中心 | (1, 1) | (3, 4) |
| 每维标准差 σ | 1.0 | 1.0 |
| 训练样本数 n | 100 | 100 |
| 测试样本数 m | 10 | 10 |

两类中心距离 ‖c2−c1‖ ≈ 3.61，略大于 2σ ≈ 2.83，因此数据"大体可分"但存在少量重叠样本（这直接影响主实验能否完全收敛，见 §4.1）。

## 3. 算法原理

**模型**：`f(x) = sign(w·x + b)`

**原始形式更新规则**：当样本被误分类（`y_i(w·x_i + b) ≤ 0`）时

```text
w ← w + lr · y_i · x_i
b ← b + lr · y_i
```

- **收敛性**（Novikoff 定理）：当数据线性可分时，误分类更新次数存在上界，算法有限步内收敛。
- **Pocket 算法**：本数据存在重叠样本、并非严格线性可分，因此在每轮遍历后检查"累计正确数"，若超过历史最优则将当前 `(w, b)` 存入口袋；训练结束时返回口袋中的最优参数，避免最终一轮参数劣化。
- 学习率 `lr = 0.1`（取较小值以抑制参数在重叠区域的振荡），最大 500 轮。

## 4. 实验内容与结果

### 4.1 主实验

流程：生成数据 → 绘制训练散点图 → 训练 → 绘制分类面 → 测试集评估 → 绘制训练/测试集+分类面 → 结果分析。

示例运行结果（`seed=42`）：

| 指标 | 值 |
|---|---|
| 最终分类面（口袋最优） | −0.2785·x1 − 1.2619·x2 + 3.6000 = 0 |
| 口袋最优训练正确率 | 194/200（97.0%） |
| 训练集错误率 | 3.00%（6/200） |
| 测试集错误率 | 5.00%（1/20） |
| 两类中心到分类面距离 | 1.59 / 1.77（近似均衡，分类面位置合理） |

由于存在少量样本重叠，每轮遍历仍约有 4 个误分样本，500 轮内未完全收敛；Pocket 机制保证了最终返回的参数是全程最优的。

输出图像：`fig1_training_data.png`（训练数据）、`fig2_classification.png`（分类面）、`fig3_train_test.png`（训练集+测试集+分类面）。

### 4.2 附加题 1：不同学习率下的迭代过程

固定数据，分别用 `lr ∈ {0.1, 0.5, 1.0}` 训练，绘制第 1/5/10/20/50/100 次迭代的分类面（3×6 子图网格），并统计各学习率下 100 轮后的错分数与最终 `w, b`。

- **观察**：学习率越大，单次更新步长越大，分类面在数据重叠区域振荡越明显；`lr=0.1` 最平稳。
- 输出：`add_fig1_lr_iterations.png` + 终端汇总表。

### 4.3 附加题 2：去掉误分类判断条件

去掉 `if y_i(w·x_i+b) <= 0` 判断后，**每个样本都会无条件执行更新**。此时参数退化为训练集标签信息的不断累加（`b` 收敛到常数，而 `‖w‖` 随更新次数**线性增长**），分类面方向由各类样本的总体分布主导并剧烈漂移。

- 输出：`add_fig2_no_check.png`（(a) 有/无判断的 `‖w‖` 演化对比；(b) 正确版本分类面；(c) 错误版本分类面）与 `add_fig2_no_check_detail.png`（错误版本在第 1/20/50/100 轮的分类面剧烈变化）。

### 4.4 附加题 3：线性不可分数据

构造强重叠数据：中心 (0, 0) 与 (1, 1)，距离 1.41 < 2σ ≈ 2.83。

- **结论**：循环不会终止——错分样本数在固定区间内**持续振荡**（500 轮后仍有错分），且 `‖w‖` 随轮数**持续增长**（更新不断发生、模长无界）。这验证了感知机收敛定理（Novikoff）的前提是"线性可分"。
- 输出：`add_fig3_inseparable.png`（(a) 错分数随 epoch 变化；(b) `‖w‖` 随 epoch 增长）。

### 4.5 附加题 4：数据中心距离的影响

固定类别 1 中心 (1, 1)，将类别 2 中心从 (3, 3) 移到 (10, 10)，覆盖 5 档中心距离 `d ≈ 2.0 / 3.6 / 5.7 / 8.5 / 12.7`。

- **结论**：错分率随中心距离增大单调下降——d=2.0 时两类高度重叠、错分率约 10% 量级；d ≥ 8.5 后基本可分；d=12.7 时严格可分（错分 0）。
- 输出：`add_fig4_center_distance.png`（5 子图）+ 终端汇总表（含各档错分数、`w, b`）。

### 4.6 附加题 5：高维扩展（100 维）

将数据生成扩展到 100 维（两类中心为全 1 与全 3 向量），训练 100 维感知机并与 2D 版本对比：

- 由于中心距离按维度累加（‖c2−c1‖ = √(100·4) = 20，而每维噪声贡献 √100·1 = 10），**维度越高信噪比越高**，100 维训练/测试准确率接近 100%，显著优于 2D 版本。
- 数值结果直接打印在终端。

## 5. 复现说明与已知问题

- **`perceptron.py` 的 `history` 列表从未被填充**：函数文档写明其应为"每轮错分样本数记录"，但循环中缺少 `history.append(...)`，导致主程序第 [7] 步打印的"收敛所需轮数 / 总参数更新次数"恒为 0。这不影响训练、口袋参数与全部图像。
- **附加题 1 的子图与标题不一致**：`epoch_wb[col]` 取的是索引 0–5（即第 0–5 次迭代后的分类面），而子图标题写的是"第 1/5/10/20/50/100 次迭代"。如需严格对应，应改为按 `check_epochs` 精确索引。
- 所有实验固定随机种子，重复运行结果一致；图像以 150 dpi 保存到脚本所在目录。
